# Quality check of raw and trimmed reads
This directory contains quality control reports for the paired-end *E. coli* reads (SRR064642 and SRR064643).

The qualisty was checked using FastQC.

raw_reads depository includes:
* fastqc.html reports for both raw paired reads 
* multiqc_report.html – Aggregated MultiQC report for both raw paired reads.

trimmed_reads depository includes:
* fastqc.html reports for both trimmed paired reads 
* multiqc_report.html – Aggregated MultiQC report for both trimmed paired reads.
